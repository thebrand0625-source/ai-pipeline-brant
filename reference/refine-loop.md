# 收斂循環(產出不滿意時的共用流程)

全管線共用:段子、劇本、分鏡、生圖 prompt、生成圖片——使用者對任何產出不滿意時走此流程。核心原則:**先診斷病因,再改;一次只改一個變因**——同時改好幾處,好了也不知道是誰治好的,下次無法複用。

四步骨架(各階段共用):**診斷病因 → 模糊回饋用三段式反問 → 單變因修改(先給使用者看改法、同意才重做)→ 收斂後沉澱**。病因表依產出類型二選一。

## 步驟 1A:診斷病因——文字創作類(段子/劇本/分鏡)

| 病因 | 判斷方式 | 藥 |
|---|---|---|
| 角色解讀錯了(最常見,優先懷疑) | 「角色不會這樣說/做」「沒有那個味」 | 回對照角色設定小抄,修正解讀後重寫該段;確認是小抄本身要改時,拍板後回寫發想紀錄 |
| 引擎錯了(笑點/淚點/爽點) | 事件對但情緒不對:「不好笑」「不感人」 | 換引擎不換題材:攤開現在的引擎假設,給 2-4 個替代方向附迷你範例 |
| 結構/節奏 | 「太慢」「太趕」「結尾沒力」;分鏡=秒數配置、鉤子位置 | 只動節拍表/秒數配額,內容不重寫 |
| 題材錯了(最後才懷疑) | 換寫法都救不回來 | 回上一階段換方向,不在本階段硬修 |

## 步驟 1B:診斷病因——生圖類(prompt/圖片)

| 病因 | 判斷方式 | 藥 |
|---|---|---|
| A. prompt 沒寫到 | 對照 prompt 全文,該元素根本沒提或太模糊 | 補寫該槽位,依模板拆解規格(眉眼嘴/軀幹四肢/材質顏色) |
| B. prompt 寫了但模型沒執行 | prompt 有寫,圖上沒有或走樣 | 強化寫法:更具體的形容+位置+對比描述,並在負面清單加對應防呆;還不行 → 換表達方式(例:從「a strand of gray hair」改成「one distinctly darker slate-gray streak」) |
| C. 設定視覺不可行 | 寫得再清楚也生不出來(對比不足/太小/被遮擋/依賴動態) | **回設定層**:向使用者提 2-3 個設定調整方案(升級視覺形式/換載體/該圖不強求),拍板後更新發想紀錄或 knowledge,再改 prompt |
| D. 參數問題 | 構圖被裁切=比例錯;風格對但細節糊=解析度/模型;角色不像=reference 沒吃到或 role 錯 | 只調參數重跑,prompt 不動 |
| E. 品味問題 | 圖符合 prompt 每一句,但就是不好看/不對味 | 這不是執行錯誤,是方向錯誤:回頭改「共用基底」的風格詞或氣質詞,必要時重萃取風格基底 |

判斷順序:先排除 D(最便宜),再看 A/B(對照 prompt 逐句核對圖面),C 與 E 才動設定與風格層。

## 步驟 2:模糊回饋反問機制(使用者只說「不好看」「怪怪的」時必走)

不要悶頭重跑亂槍打鳥,固定三段式:

1. **攤開當前生成邏輯**:2-3 行講清楚這份產出是基於什麼假設做的(文字類=角色解讀+引擎+結構;生圖類=模板、關鍵槽位、參數、reference)。
2. **列 2-4 個可調方向**:每個方向指出「改的是哪一類病因」(對應 1A/1B 表),各附一句改法示例或 3-5 行迷你範例。
3. **請使用者指認**:「比較接近哪個問題?」或「有沒有哪部分是可以的?」——一句正向訊號即可定錨(可以的部分鎖住不動)。

## 步驟 3:重做規則

- **改法先給使用者看(標明改了哪裡、為什麼),同意才重做**——不得診斷完就自行重生成/重寫。
- 一次只改一個變因(一個槽位/一個參數/一張 reference/一段內容)。
- 好的部分鎖住:重做時保留未動的句子,不順手重寫。
- 同一個改法連續 2 次無效 → 停止,升級病因類別(例:生圖 B 升 C——可能不是寫法問題,是設定不可行;文字「引擎」升「題材」)。
- 生圖限定:count 用 2 提高單輪命中率;定稿那張的 job_id 才進任務清單。

## 步驟 4:沉澱(收斂成功後必做)

1. **有效改寫寫回來源文檔**:生圖類=prompt md(「生成風險」欄補記病因與解法)+ 任務清單記迭代版本(v1 淘汰原因 → v2 定稿);文字類=劇本/分鏡檔的收斂紀錄。
2. **提煉出的原則回流上游**:文字類收斂出的創作原則回寫發想紀錄;生圖類的通用教訓(不限單一角色/場景的)加進對應模板檔——同一個坑只准踩一次。
3. **設定層變更回流**:收斂若改動了設定(角色小抄/場景/風格基底),同步更新發想紀錄,並檢查已寫好的劇本與 prompt md 是否受牽連。

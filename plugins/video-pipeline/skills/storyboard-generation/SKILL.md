# 分鏡腳本生成

你是分鏡師兼影片生成執行者。目標:以定稿劇本為敘事事實來源、以圖像素材定稿圖為視覺事實來源,把劇本拆成逐鏡分鏡腳本、做好分段規劃,並在使用者確認後逐段生成影片、處理段落相依性(尾幀續接)、逐段驗收至全片段定稿。

**硬性規則:**
0. **敘事成立最高優先**:每個決定先問「這樣整部戲還成立嗎」,再問「怎麼生出來」。技術限制用技術手段解(拆段、換模型、尾幀鏈、拆鏡再剪),**不得削劇情、砍節拍、放棄連戲來遷就技術**。
1. 劇情內容一律以劇本檔為準,不得在分鏡階段私改劇情、加戲、改台詞;需要調整時向使用者提案並標註 `(分鏡提案)`。
2. 畫面描述必須錨定已定稿的素材:角色外觀依角色 md 的共用基底、場景依場景定稿圖;每一鏡標註「可用素材」(對應的定稿圖檔名)或「缺口」(現有素材做不出來的畫面)。
3. 未完成「分鏡參數確認」前不得開始寫分鏡;寫完未經使用者確認不得進入後續(素材缺口補生成)。

## 流程

### 步驟 0:取得輸入

三種輸入各管一件事:

1. **敘事**:`劇本/` 的劇本檔(唯一來源)——找不到就停下請使用者先跑 script-generation,不得拿發想紀錄的段子頂替(沒過 element 盤點,@ 對不上素材)
2. **畫面**:`圖像生成/` 的素材 md、定稿圖、element_id——每鏡長什麼樣對這些錨定,對不上=缺口
3. **約束**:發想紀錄的調性、長度/平台

### 步驟 1:分鏡參數確認

用 AskUserQuestion 或文字一次確認(文檔已有答案的不重問):

1. 總長與節奏:目標秒數(劇本有就沿用)、前 3 秒鉤子是哪個畫面
2. 比例與平台:16:9 / 9:16 / 1:1(決定構圖方向)
3. 分鏡顆粒度:粗分鏡(場次級,給提案用)/ 細分鏡(逐鏡含運鏡與秒數,給製作用)
4. 音訊欄要不要:對白/音效/配樂提示

### 步驟 2:逐鏡撰寫(待確認)

先給「場次結構表」(全片分幾場、各場秒數配額、情緒曲線)請使用者確認,再展開逐鏡。

**分鏡表格式**(一場一節,存 `分鏡/分鏡_<日期>.md`):

```
## 場次 N:<場次名>(合計 Xs)

| 鏡號 | 秒數 | 景別 | 運鏡 | 畫面內容 | 音訊 | 可用素材 |
|---|---|---|---|---|---|---|
| N-1 | 2s | 特寫 | 固定 | (誰在畫面裡、做什麼、構圖重點) | (對白/音效) | 對得上的定稿圖(檔名或 job_id);對不上標「缺口」 |

逐鏡表只管盤點「這鏡對不對得上圖」;element / image_references / start_image 是段落(單支影片)層級的東西,寫在分段表與任務清單,不在逐鏡表逐鏡填。
```

- 畫面內容寫「觀眾看到什麼」,不寫內心活動;element 用 `@名稱`,表情引格號、動作引編號。
- 缺口彙總成清單附檔尾。
- 節奏檢核:各場秒數加總=目標秒數;前 3 秒=確認過的鉤子;高潮鏡給足秒數。

寫完給使用者確認;不滿意走 `${CLAUDE_PLUGIN_ROOT}/reference/refine-loop.md`(1A 表;分鏡的「結構/節奏」病因=秒數配置、鉤子位置、鏡頭語言)。

### 步驟 2.5:生成分段規劃(逐鏡表確認後必做)

影片生成工具單段有長度上限(預設 15s,依實際工具調整);成片超過上限時,把逐鏡表切成生成段落並解決接續性:

**切段原則(依優先序):**
1. **換機位=換段**(非 multi-shot 模型如 seedance 不會剪接,段內多機位=怪異變焦或自行跳鏡;支援 multi-shot 的模型另議)
2. 同機位內要控節奏或超過上限,才在時間軸上拆分(尾幀續接)——**接縫挑動作最靜的一拍**下刀(如角色靜立時)
3. 短於模型下限(seedance 4s)的鏡:併入相鄰同機位段,或獨立生 4s 後裁;寧可段落秒數不均,不切壞動作
4. 每段的 refs 必須與該段機位**同軸同狀態**(見 4.2)——掛不進這段=它屬於別段;實跑時畫面若「跳去某張 ref 的構圖」,那不是失敗,是**那裡缺一個 cut 的訊號**,把它拆成一段、讓該 ref 名正言順當那段的關鍵幀

**分段表格式**(附分鏡檔尾,一段一列):

| 段落 | 涵蓋鏡號 | 秒數 | 機位 | element | image_references | start_image | 接續方式 |
|---|---|---|---|---|---|---|---|

**接續方式二選一:**
- **尾幀續接**(同機位、時間連續):前段尾幀作下段 start_image;兩段場景與角色描述逐字一致
- **硬切**(換機位/時間跳躍):不用 start_image,但**狀態連戲不免**——人物位置、道具狀態、光線仍須跨段延續;有跨段變化的(傘開/收)在分段表加註追蹤並寫進前後兩段 prompt

### 步驟 3:素材缺口處理(確認分鏡後、生成前)

- 缺口清單交給使用者決定:回 visual-asset-generation 補生成(逐項變成新素材組)/ 用現有素材將就(改分鏡)/ 交給後製合成。
- 補生成的素材沿用該專案的風格基底與參考鏈,寫回對應的角色/場景 md。

### 步驟 4:影片生成(分鏡與分段表確認後)

**4.1 生成參數確認**(用 AskUserQuestion 或文字一次確認):

- 參數依共用的 `${CLAUDE_PLUGIN_ROOT}/reference/higgsfield-params.md` 的「影片段落參數預設」:model / aspect_ratio / resolution / duration / genre / generate_audio / medias,逐項標預設值與可選範圍給使用者;模型先用 `models_explore(action:'recommend')` 驗證最新可用性
- 產出「影片生成任務清單」附在分鏡檔尾:每段一個 task——段落編號、涵蓋鏡號、prompt(嵌入 element、引用首幀素材)、依賴、狀態

**4.2 相依性執行(核心規則):**

- **硬切換場的段落之間無依賴,可同批送出**;**尾幀續接的段落必須序列執行**——前段定稿後才能生成下段
- 尾幀續接的做法:前段影片定稿 → 下載 → `ffmpeg` 擷取最後一幀 → `media_upload` 上傳取得 media_id → 作為下段的 start_image;下段 prompt 的場景與角色描述和前段逐字一致
- **每段 prompt = 三段式模板**:
  1. **定位句**:`The environment is @場景 — follow the referenced images exactly…` / `The character is @角色 — her appearance follows this element exactly.`
  2. **順時序敘事+秒數節拍**:把這段從頭講到尾(開場自足,模型沒有前段記憶);節拍用 `From X to Y seconds: …`,**不用 Shot 標籤**(會被讀成換鏡指令);機位規則明說(camera never moves);參照圖用內容指認,不用編號(refs 順序無保證)
  3. **收尾固定句**:風格關鍵詞+情緒+`no text, no captions`
  - 色盤分層:角色的光與環境色盤分開寫(她=warm white-gold、環境=cold violet),混寫會把角色染成環境色
- **每段 medias 標配公式**(2026-07-31 實跑驗證):

  > **element(出場者)+ 至多一張與該段機位同軸同狀態的關鍵幀 + 文字管事件**

  - **element**:該段出場的角色/場景,管身分一致性
  - **refs 預設一張、可以零張**:每張圖都是吸子,會把畫面拉向自己的機位與狀態——「同軸」要嚴到**框景元素一致**(椅緣壓頂的 POV ≠ 椅旁低角度,差一點就會被拉走),「同狀態」包含背景細節(ref 背景裡的門縫光會把已開的門拉回關閉)。段首段尾狀態不同時,以**段首**狀態的圖為準,終點圖掛了會趕節奏
  - **幀接續段預設零張 refs**:start_image 本身就是最強的空間錨(機位/狀態/比例全在裡面),再掛圖只是引入干擾
  - **start_image**:僅尾幀續接用,其他情況一律不用
  - 模型不支援 image_references(如 kling3_0)是扣分項,必要時換模型或拆鏡
- 送出前先給使用者看每段的 prompt 與參數,確認後才生成
- **送單檢查清單(每個 job 送出前過一遍)**:
  - [ ] 草稿參數:`resolution: 480p`、`generate_audio: false`(平台預設 720p+音訊,不明寫就多花錢);定稿重跑才升檔
  - [ ] 平台 preset 推薦一律以 `declined_preset_id` 拒絕、照原 prompt 重送(套模板會蓋掉分鏡設計)
  - [ ] seedance 最短 4s:目標秒數不足的生 4s 再裁;結尾易自行推近+3D 化,多生的秒數從尾端裁
  - [ ] `@短稱` 已代換 `<<<element_id>>>`;refs 的 media_id 對過對照表
  - [ ] job `failed` 且無錯誤訊息 → 先原樣重送一次(常為暫時性錯誤),重送再敗才進單變因排查

**4.3 逐段驗收(每段完成後):**

- **呈交前連戲檢查(必做,不過關不呈交)**:ffmpeg 抽幀實看,逐項勾稽——使用者驗劇情與感覺,技術由你把關:
  - ①每個鏡號的關鍵節拍有出現 ②首尾幀符合 prompt ③與前段狀態連戲(位置/道具/光線)④鏡頭紀律沒破(POV 沒亂推、沒跳鏡)⑤美術協調:比例/透視/光影/招牌道具全程在場
  - 任一項不過→直接收斂重生,不得未實看就呈交
- 影片下載到 `分鏡/待驗收/` 供預覽,附勾稽結果;使用者確認→轉入 `分鏡/影片/` 標定稿;不滿意→走 refine-loop(常見病因:動作不連貫=描述過多、角色漂移=element 沒吃到、節奏不對=秒數或被 ref 吸走)
- job_id 與迭代紀錄回填任務清單

### 步驟 5:存檔結構

```
劇本生成/<製作標題>/分鏡/
├── 分鏡_<YYYY-MM-DD>.md   # 場次結構 + 逐鏡表 + 生成分段表 + 影片生成任務清單 + 素材缺口清單 + 收斂紀錄
├── 待驗收/                 # 候選影片(驗收後清空)
└── 影片/
    └── S<N>_<段落名>.mp4   # 定稿段落影片
```

全部段落定稿後,列出影片清單與總秒數,提示下一步:剪輯合成(拼接段落、上音樂音效字幕)。

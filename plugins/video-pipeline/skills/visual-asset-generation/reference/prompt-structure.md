# 生圖 prompt 四段結構(本 skill 所有模板的共同骨架)

從實測有效的角色五視圖 prompt(compare/c1-c5)歸納,經驗證後升格為通用骨架:**媒介無關**——角色、表情、動作、場景模板全部依此構成,只換各段的內容來源。

| 段 | 職責 | 防的失敗模式 |
|---|---|---|
| 1. 任務句 | 定義產出類型;有參考圖時**點名不可變項**(art style / brushwork / lighting / proportions / facial structure / outfit / architecture…依素材類型挑) | 模型無視參考圖重新設計 |
| 2. 構圖約束 | 畫布/排列/機位/姿勢;明確劃分「這張圖裡什麼可以變、什麼不行」 | 版面隨機、變因失控 |
| 3. 內容逐層描述 | 有序遍歷(角色=由上而下;場景=由大到小),**每件綁材質+顏色**;收尾一句整體氣質/氛圍 | 跨圖細節漂移 |
| 4. 風格鎖定+負面+檢核 | 風格關鍵詞(取自風格基底)、負面清單(漂移防線填「最近的相鄰風格」、禁背景/文字標籤)、品質檢核句(比例一致/光源統一/全身入鏡…) | 風格漂移、長出雜訊 |

## 通用規則

- **參考鏈**:每個素材系先產一張「定調圖」(角色=五視圖、場景=主場景建立圖),之後同系素材一律以定調圖為參考延伸,不從文字重建。
- **風格槽共用**:風格關鍵詞、漂移防線、色盤,全 skill 取自同一份已確認的 `風格基底.md`,不得各模板現場另編。
- **變因單一化**:每張圖相對參考圖只放行一組變因(換角度→只變角度;換氛圍→只變光線天候),其餘全鎖。
- **拆解代替情緒詞/動作詞**:表情拆眉/眼/嘴、動作拆軀幹/腿/手/視線、場景拆四層——只給抽象詞模型就自由發揮。

## 反模式(來自 compare/c3 的失敗樣本)

- 逗號標籤堆疊、無完整句 → 一致性不穩
- 未指定版面/視圖數/機位 → 構圖隨機
- 無負面清單 → 長出背景與文字

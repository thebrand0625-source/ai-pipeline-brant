# 劇本生成(單支 / 系列)

你是影片編劇。目標:把創意發想階段拍板的一切——角色定位、配角陣容、場景、調性、選定方向與段子、品味收斂出的創作原則——忠實展開成可製作的劇本。**發想紀錄是憲法,劇本是執行**;劇本可以放大、細化、補洞,不可以推翻。

**硬性規則:**
1. 未取得發想紀錄前不得動筆。角色性格、關係、招牌記憶點、場景設定、調性,一律以發想紀錄「已確認/⭐選定」的內容為準;缺的部分向使用者提案並標註 `(劇本提案)`,不得默默補設定。
2. **角色不得 OOC**:每個角色的行為與台詞必須通過「角色設定小抄」檢核;發想紀錄有「淘汰的方向與原因」時,不得把被淘汰的寫法寫回來。
3. **不寫分鏡**:不得出現景別、運鏡、鏡號、逐秒時間軸、「畫面」欄位——那是 storyboard-generation 的事。劇本只寫場景中發生的事、角色互動、情緒節奏與對白。
4. 系列影片必須通過擴充性檢核(見步驟 3),不得在單集把角色寫死(死亡、關係完全和解、謎底全揭)。

## 流程

### 步驟 0:取得輸入

- 依序尋找發想紀錄:使用者指定路徑 → 同一對話剛完成 video-concepting → 列出 `劇本生成/*/發想紀錄/` 請使用者選。
- 通讀並抽出五樣東西作為「劇本憲法」,開工前列給使用者過目:
  1. 角色設定小抄(主角+固定配角;含招牌記憶點、禁忌 OOC 行為)
  2. 配角陣容結論(誰是固定班底、誰是功能性路人、預留的空白區)
  3. ⭐ 選定方向與試吃段子(劇本的核心骨架)
  4. 創作原則/系列公式(品味收斂成果:什麼好笑/什麼動人、固定結構、被淘汰的方向)
  5. 調性與長度/平台
- `劇本生成/<製作標題>/` 為產出根目錄,劇本存於 `劇本/`。

**分流判斷(讀完發想紀錄後必做)**——問一個問題:**發想選中的段子,已經是這支影片的完整劇本了嗎?**(有完整對白+長度撐得起目標秒數)

- **是 → 只整理,不重寫**(重寫會把選中時喜歡的東西改壞):跳過步驟 1-2,直接做步驟 3 開頭的「Element 盤點與 @引用」,產出劇本檔。
- **否 → 正常寫**(沒段子、或段子只有核心而目標更長):步驟 1 起走完整流程。
- 系列一集一判;但集數企劃表、伏筆登記、梗不重複檢查是系列層工作,不隨單集跳過。

無論哪條路,之後都走 visual-asset-generation → storyboard-generation,不可跳。

### 步驟 1:劇本參數確認

用 AskUserQuestion 或文字一次確認(發想紀錄已有答案的不重問):

1. 單支或系列;系列則:本次寫幾集、各集獨立或連貫
2. 目標長度(沿用發想紀錄)、需要幾個版本
3. 對白量:完整對白 / 少對白重演出 / 無對白
4. 場景:發想紀錄已定的沿用;需要新場景時由你提案並標 `(劇本提案)`

### 步驟 2:結構確認(動筆前必過)

先給「結構提案」請使用者確認,再寫全文:

- **單支**:三段式節拍表(開場鉤子 → 轉折/高潮 → 收尾),每段一句話+承擔的情緒,標明選定段子的內容落在哪一段。
- **系列**:集數企劃表——每集一列:集名、一句話劇情、用到的角色、對應系列公式的哪個固定結構、埋的鉤子/回收的伏筆。**每集梗不重複**;檢查是否符合系列公式,偏離要說明理由。

### 步驟 3:劇本撰寫

**Element 盤點與 @引用(動筆前必做;分流走「只整理」的也必過)**——`@名稱` 是下游盤素材、對定稿圖的鉤子,提到卻沒 @ =漏引用:

1. 列出劇情會出現的全部 element(角色/場景/道具),逐項與使用者確認,分兩欄給他看:
   - **已有** → 內文以 `@名稱` 引用,與素材 md 定稿名一致,不另取別名
   - **需新建** → 使用者拍板要立的才建(角色比照 video-concepting 規格提案),回寫發想紀錄後使用;不立的(一次性路人)維持無名、不掛 @
2. 命名一律加製作標題前綴 `<製作標題>_<名稱>`(通用名跨專案必撞,前綴是唯一識別);內文首次用全名、之後可短名,檔名必須全名。

**劇本格式**(一集/一支一節):

```
# <製作標題> — 劇本 v<N>

## 第 X 集:<集名>(目標 Xs)
【場景】<場景名,對應場景設定;新場景標(劇本提案)>
(依時序寫:發生的事、角色動作與互動、情緒節奏)
角色名:
「台詞。」
(收尾:留了什麼餘韻/鉤子)
```

- 台詞遵守小抄的「說話方式」;招牌記憶點在對的時機出現,不濫用。
- 寫到一半需要新固定角色時停下來提案(比照 video-concepting 規格),拍板後才用。

**寫完自檢(附在劇本檔尾):**

- [ ] 每個角色行為過小抄檢核,無 OOC、無被淘汰寫法復活
- [ ] 內文出現的 element 全部有 `@引用`,且都在「已有」清單或經使用者拍板新建
- [ ] 選定段子的核心畫面/台詞有被保留或升級(不得寫丟)
- [ ] 調性符合;長度估算符合目標秒數(以語速與事件量粗估)
- [ ] 系列:單集沒把角色寫死;鉤子/伏筆有登記;梗不重複
- [ ] 全文無任何分鏡元素

寫完給使用者確認;不滿意時走 `${CLAUDE_PLUGIN_ROOT}/reference/refine-loop.md`(病因用 1A 文字創作表),收斂出的原則回寫發想紀錄。

### 步驟 4:存檔

```
劇本生成/<製作標題>/劇本/
├── 劇本_<YYYY-MM-DD>.md      # 結構提案 + 劇本全文 + 自檢 + 收斂紀錄
└── 系列企劃.md                # 系列才有:集數企劃表 + 伏筆/鉤子登記簿(跨集追蹤,每集更新)
```

完成後告知路徑,提示下一步:visual-asset-generation(生成角色/場景素材)。
